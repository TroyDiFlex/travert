## Что уже работает

- Счета: создать, переименовать, удалить (RUB, USD, EUR).
- Категории: создать, переименовать, удалить; цвет и 184 локальные Lucide-иконки с русским поиском.
- Расходы: добавить, изменить, удалить; фильтры по месяцу, счёту и категории.
- При удалении категории или счёта — выбор: удалить вместе с расходами или переназначить каждый расход отдельно.
- Демо-данные из `finance/demo-seed.json` подтягиваются сами при первом запуске; кнопки «Скачать JSON» и «Сбросить демо» — для экспериментов.

## Запуск локально

```sh
python -m http.server 8000
```

Затем открыть `http://localhost:8000/index.html#entries-expenses`. Двойным кликом по файлу не открывать: браузер режет ES-модули через `file://`.

Проверки: `node scripts/check-js.mjs`, затем `node --test tests/*.test.mjs`.

## Наследие Потока

Доходы (`index.html`: обзор, ввод данных, корзина, импорт/экспорт) тоже работают локально без входа и сервера: данные лежат в `localStorage` через `local-income.js`. Формат ревизий, корзины и резервных копий повторяет сервер, Drive-копии недоступны — используйте «Скачать JSON». Исходный продукт с Google Таблицей живёт отдельно в `income-dashboard`.

## Что умеет Поток

| | |
| :--- | :--- |
| **Вся динамика** | Линия, столбцы или плавный график. Всё время, отдельный год или свой период. |
| **Нужные источники** | Выбор нескольких источников и сравнение их доходов на одном графике. |
| **Понятные показатели** | Общая сумма, средний и медианный доход, лучший месяц и самый прибыльный источник. |

| **Удобный ввод** | Годовая таблица, форма на месяц и быстрое добавление дохода. |
| **Свои настройки** | Названия, цвета и статусы источников, шесть тем, установка как приложения. |

## Как считаются данные

- **Пропуск ≠ ноль.** Пустое поле означает отсутствие записи, `0` — месяц без дохода. Пустое поле при редактировании удаляет запись.
- **Одна сумма на источник за месяц.** Повторное сохранение заменяет эту сумму.
- **Среднее** учитывает месяцы с записями. При сравнении источников для каждого используются его месяцы с записями.
- **Медиана** считается за шесть полных месяцев перед текущим; выбранный период её не меняет, фильтр источников — меняет.
- **Неактивные источники** остаются в истории и расчётах. Удалённые попадают в корзину на 30 дней и до восстановления исключаются из аналитики.
